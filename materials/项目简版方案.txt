《虫迹中国——AI自然观察站》简版方案

一、一句话介绍

这是一个给中小学生使用的“AI昆虫观察站”：Arduino记录发现昆虫时的温度、湿度和光照，学生用小程序上传昆虫照片并填写观察描述，AI给出候选种类和科普讲解，再生成可以保存、分享的自然明信片。


二、我们为什么做

很多学生在课本里认识昆虫，却叫不出校园、农田和湿地里常见昆虫的名字。我们希望让孩子从身边的一只虫开始，学会观察、记录、提问和交流。

这个项目可以结合以下方向进行介绍：

1. 人工智能赋能科学教育。
2. 博物教育和生态文明教育。
3. 让城市与乡村学生交流各自发现的自然物种。
4. 记录祖国不同地区的自然环境，服务城乡融合和乡村振兴主题。

它不是单纯的“AI拍照识虫”，重点是把环境数据、学生观察、AI讲解和作品交流连成一个完整过程。


三、整个系统怎么工作

第一层：环境感知

Arduino UNO R3连接DHT11和光敏电阻，采集温度、湿度和相对光照。

第二层：电脑连接

Arduino通过USB线连接电脑，把传感器数据直接发送给本地服务，不需要Wi-Fi模块。

第三层：小程序观察

学生在微信开发者工具里的小程序中选择或拍摄昆虫照片，并输入发现地点、昆虫颜色、大小和行为等描述。

第四层：AI分析

Kimi结合照片、文字描述和传感器数据，给出最多三个可能的昆虫候选，并说明判断依据、不确定之处和下一步应该观察什么。

第五层：作品生成与交流

GPT Image 2生成一张没有文字的昆虫艺术插画，系统再把照片、插画、环境数据和科普文字排版成自然明信片和博物详解图。学生可以把PNG图片保存到电脑，也可以发布到本机的“自然中国”交流广场。


四、需要使用的东西

硬件：

1. Arduino UNO R3一块。
2. DHT11温湿度传感器一个。
3. 光敏电阻一个。
4. 10kΩ电阻，给光敏电阻组成分压电路。
5. 面包板、杜邦线和USB数据线。
6. 热释电传感器可以作为加分项，用于检测有没有学生来到观察站前。

风扇和马达这次不作为主要功能。它们如果要展示，只能做展台效果，不能直接接Arduino引脚。

软件：

1. Arduino采集程序。
2. 运行在电脑上的本地服务。
3. 微信开发者工具测试号小程序。
4. Kimi多模态接口，模型为k3。
5. GPT Image 2生图接口。
6. Windows本地中文语音，用来朗读科普内容，不需要TTS密钥。


五、第一版必须做出的功能

1. 小程序能看到Arduino传来的实时温度、湿度和光照。
2. 能选择一张昆虫照片，并填写观察描述。
3. Kimi能返回候选昆虫、判断依据和观察建议。
4. 页面明确提示“AI结果仅供辅助观察，不是权威鉴定”。
5. 能播放儿童版中文语音讲解。
6. 能生成一张自然明信片和一张博物详解图。
7. 图片能以PNG格式保存到电脑。
8. 作品能发布到本机交流广场，并按地区或场景查看。
9. 没有网络或AI接口出错时，仍能用预置内容完成演示。


六、现场演示流程

整个演示控制在三到五分钟。

第一步：展示硬件。

把Arduino连接电脑。用手捂一下DHT11，或者用手机手电筒照光敏电阻，让页面上的环境数据发生变化，证明数据来自真实传感器。

第二步：建立观察记录。

在小程序中选择一张提前准备好的清晰昆虫照片，地点选择“校园花坛”或“乡村农田”，再输入一句观察描述，例如：“它停在叶片背面，身体绿色，大约两厘米。”

第三步：让AI分析。

点击“请AI博物导师分析”。页面显示三个以内的候选昆虫，同时显示判断依据、不确定性和继续观察建议。

第四步：听讲解。

点击播放按钮，由Windows本地中文语音朗读儿童版科普内容。

第五步：生成作品。

点击“生成自然明信片”。系统生成昆虫插画，并把照片、温湿度、光照、地点和科普文字排成一张完整图片。

第六步：发布交流。

把明信片发布到“自然中国”广场，再展示来自校园、湿地和农田的不同观察记录。最后说明未来可以连接更多城乡学校，形成共同维护的自然观察地图。


七、老师问到时怎么解释

为什么没有固定摄像头？

因为手机和小程序本身就能提供更清晰、更灵活的图片。Arduino只负责采集客观环境数据，二者各做擅长的部分，能降低硬件成本。

这和普通识虫软件有什么区别？

普通识虫软件通常只回答“这是什么”。我们的系统还记录“在哪里发现、当时环境如何、为什么这样判断、接下来观察什么”，最后把观察结果变成作品并用于城乡学生交流。

AI会不会认错？

会，所以系统只给候选答案，不说百分之百确定。它还会告诉学生缺少什么证据，引导学生继续观察，而不是代替学生思考。

这和昆虫旅馆有什么关系？

昆虫旅馆不只是一座木头结构，也可以是一处长期观察昆虫活动的自然学习站。我们的系统相当于给昆虫旅馆增加环境记录、AI讲解和教育交流能力。即使活动现场没有制作旅馆的材料，也可以先完成数字观察部分。


八、明确不做的事情

1. 第一版不制作真正的木质昆虫旅馆。
2. 不购买或安装固定摄像头。
3. 不做权威物种鉴定，不用于有毒有害昆虫的安全判断。
4. 不做真正的全国社交平台，交流广场只在演示电脑本地运行。
5. 不做复杂账号、支付、评论审核和真实学校认证。
6. 不强行使用风扇、马达等与核心体验无关的器件。


九、演示失败时的备用方案

1. Arduino连接失败：切换到模拟环境数据，并在页面标明“演示模式”。
2. Kimi接口失败：使用提前准备的分析结果继续展示。
3. 生图接口失败：直接使用学生上传的原始照片生成明信片。
4. 语音播放失败：保留完整文字讲解，不影响其他流程。
5. 现场网络较差：提前准备好一条完整观察记录和生成好的图片。


十、最实际的开发顺序

第一阶段：先做Arduino数据采集和电脑串口读取。

第二阶段：做小程序的观察首页、图片选择和数据展示。

第三阶段：接入Kimi、GPT Image 2和本地语音。

第四阶段：制作明信片、详解图、交流广场和完整演示数据。


十一、汇报时可以直接说的总结

“虫迹中国”希望把一次偶然的昆虫发现，变成一次完整的科学学习。孩子不仅能知道它可能是什么，还能记录它生活的温度、湿度和光照，理解AI为什么这样判断，并把自己的发现制作成自然明信片，与不同地区的同学交流。我们想让人工智能不只是替孩子给答案，而是带着孩子重新认识身边的自然，也重新认识祖国不同地区真实而丰富的生态环境。
